# Rodrigo Marcelo — Portfolio

Site portfolio de Rodrigo Marcelo, realizador e production designer.

Vanilla HTML/CSS/JS, sem build step. Estética rough/DIY — glitch type, marquees,
grain/scanlines, cards "coladas" com fita adesiva — inspirada na identidade visual
crua e internet-native de artistas como 2hollis e Frost Children.

## Estrutura
- `index.html` — conteúdo e secções
- `style.css` — todo o styling / efeitos visuais
- `script.js` — render dos projetos, modal de vídeo, cursor custom, menu mobile
- `favicon.svg`

## Correr localmente
Basta abrir `index.html` num browser, ou:

```bash
python3 -m http.server 8000
```

## Deploy
Publicado via GitHub Pages a partir da branch `main`.
